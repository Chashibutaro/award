# 表彰用ページ（入力・表示）

このリポジトリは、日々の表彰データを入力・保存し、綺麗なレイアウトで表示・共有するためのシンプルな静的サイトです。

## 概要
- `入力.html`: 日付、午前／午後／本日の総合の各部について「ISR名」「値」を入力し、`localStorage` に保存します。また公開用として`award.json`出力（コピー）やGitHub保存（PAT利用）も提供します。
- `表彰用.html`: 公開用の `award.json` を優先的に読み込み、存在しない場合のみ `localStorage` を参照します。部切替（午前／午後／本日の総合）、CSV／JSON出力、印刷、共有を提供します。

## ファイル構成
- `入力.html`
- `表彰用.html`

## 使い方（ローカル確認）
1. ローカルサーバを起動してページにアクセスします（例: `http://127.0.0.1:8080/`）。
   - 例: `npx http-server -p 8080` でこのフォルダを配信
2. `入力.html` を開いて必要なデータを入力し、「保存」を押します。
3. `表彰用.html` を開くと、共有データ `award.json`（存在する場合）または `localStorage` が読み込まれ、表示されます。
4. 出力・共有エリアから CSV／JSON、印刷、共有が可能です。

## 公開と全員反映（GitHub Pages）
- すべてのアクセスで同じ内容を表示したい場合、公開用の共有データ `award.json` を更新してください。
- 手順A（簡単・安全）:
  1. `入力.html` で編集後、「公開用JSONをコピー」をクリック。
  2. GitHub上のリポジトリで `award.json` を開き、編集画面に貼り付けて保存（コミット）。
  3. 数十秒後、GitHub Pagesに反映されます。
- 手順B（ブラウザから直接保存・上級者向け）:
  1. `入力.html` の「GitHubへ保存（PAT利用）」を開き、`owner`/`repo`/`branch`/`PAT` を入力。
  2. 「GitHubへ保存」ボタンで `award.json` をコミット。PATには`repo`権限が必要です。
  3. PATはブラウザのみで使用され、ページ上に保存しません。

## 補足
- `localStorage` は個別ブラウザにのみ反映されるため、全員に同じ表示をさせたい場合は `award.json` を更新してください。
- 共有ボタンは Web Share API を利用し、非対応環境ではURLコピーのフォールバックを行います。
- セキュリティのため、PATの取扱いには十分注意してください。
